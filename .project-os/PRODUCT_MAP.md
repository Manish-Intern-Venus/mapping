# PRODUCT MAP

## Product Areas

### Public / Entry

Purpose:
Let the user enter the product quickly.

Expected behavior:
- Minimal login or access screen.
- No heavy marketing landing page.

### User Daily Entry

Purpose:
Capture daily boiler and autoclave readings for assigned unit(s).

Core elements:
- Current user name.
- Assigned unit selector when needed.
- Date.
- Boiler photo upload.
- Boiler extracted reading.
- Boiler consumption.
- Autoclave photo upload.
- Autoclave extracted reading.
- Autoclave consumption.
- Sign value from logged-in user name.
- Save/submit action.

### User Saved Result

Purpose:
Show that today's row was saved.

Core elements:
- sr. no.
- date
- boiler reading
- boiler consumption
- autoclave reading
- autoclave consumption
- sign

### Admin Users And Units

Purpose:
Control unit access.

Core elements:
- User list.
- Role.
- Unit assignment controls.
- Clear access state.

### Admin Reports

Purpose:
Review and export records.

Core elements:
- Unit filter.
- Date filter.
- Daily records table.
- Excel export.
- PDF export.
- Sign column.

### Admin Analytics

Purpose:
Help Admin understand saved readings and consumption trends.

Core elements:
- Unit-wise reading trends.
- Boiler consumption trend.
- Autoclave consumption trend.
- Unusual value review entry point.

## Current Prototype Screens

The current code has these screens:
- Landing
- Login/profile selection
- Unit selection
- Overview
- New Check
- Inspection
- Result
- Reports
- Analytics
- Admin

## Target Product Direction

Future implementation should reduce ordinary user screens to:
- Login
- Unit choice only when needed
- Daily upload
- Saved row/result

Admin can keep:
- User/unit assignment
- Reports
- Analytics
