# DESIGN LANGUAGE

## Experience Target

NAJAR Digital Logbook should feel simple, direct, and reliable.

The product should reduce manual effort. It should not make users feel like they are operating a complex industrial analytics suite.

## Visual World

Use the world of a clean plant log station:
- Meter display.
- Daily reading sheet.
- Unit context.
- Signed row.
- Admin logbook.

Graphics should help users understand what to upload and what was saved. They should not be decoration.

## Layout Principles

For User screens:
- Start with the task, not marketing.
- Show assigned unit clearly.
- Provide two primary upload areas: boiler and autoclave.
- Show extracted numbers prominently.
- Show consumption beside each reading.
- Show signer name in the saved row.
- Keep navigation minimal.

For Admin screens:
- Use tables and filters where useful.
- Keep reports scannable.
- Make unit and date filtering obvious.
- Analytics should stay close to the report data.

## Color Philosophy

Use restrained industrial utility colors:
- Neutral light surfaces for sheet/table readability.
- Dark text with strong contrast.
- One primary operational color for main actions.
- Amber/red only for review or warning states.

Avoid making the interface dominated by gradients, dark cinematic panels, or generic SaaS blue/purple palettes.

## Typography

Typography should prioritize reading accuracy:
- Clear numeric values.
- Stable table columns.
- Modest headings.
- No oversized hero type in the main product.
- No negative letter spacing.
- No viewport-width font scaling.

## Components

Prefer:
- Upload panels.
- Record preview rows.
- Tables.
- Simple unit selector.
- Clear admin filters.
- Buttons with familiar icons where useful.

Avoid:
- Nested cards.
- Complex dashboards for ordinary users.
- Decorative KPI blocks.
- Multi-step wizard screens unless a real future workflow requires them.

## Motion

Motion should be minimal and functional:
- Upload progress.
- OCR processing state.
- Save confirmation.
- Error attention.

Do not use large decorative motion or animations that distract from daily work.

## 3D And Illustration

3D is not needed for the current confirmed product.

Use simple bitmap/photo guidance or iconography only when it helps the user upload the correct meter display photo.

## Copy

Copy should be short and task-focused.

Use language like:
- Upload boiler photo.
- Upload autoclave photo.
- Reading found.
- Check number before saving.
- Saved with your name.

Avoid inspection-suite language such as:
- Operating envelope.
- Release criteria.
- Industrial intelligence.
- Complex lifecycle copy.
